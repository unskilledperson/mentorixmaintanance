# Mentorix Maintenance / Coming Soon Page

## 📂 Files Included
- `index.html` - The main HTML structure with SEO meta tags and modern layout.
- `style.css` - Luxury dark-mode styling, glassmorphism, responsive styles, and glowing gradients.
- `script.js` - Interactive connected-particle canvas background, live countdown timer, and notify-me form handler.

## 🚀 How to Upload to Hostinger

### Method 1: Using Hostinger hPanel File Manager (Easiest & Fastest)
1. Log in to your **[Hostinger Control Panel (hPanel)](https://hpanel.hostinger.com/)**.
2. Go to **Websites** > click **Manage** next to your domain.
3. In the sidebar or dashboard, search for **File Manager** (or click **Files > File Manager**).
4. Select **Access files of [your domain]**.
5. Navigate into the **`public_html`** folder:
   - If there is a default `default.php` or `index.html` file already from Hostinger, you can delete or rename it.
6. Click the **Upload** button (arrow pointing up icon) in the top-right toolbar.
7. Select **File** and upload:
   - `index.html`
   - `style.css`
   - `script.js`
8. Visit your domain in a browser (`https://yourdomain.com`) — your animated maintenance page is immediately live!

---

### Method 2: Uploading as a ZIP
1. Select all 3 files (`index.html`, `style.css`, `script.js`) and compress them into a `maintenance.zip`.
2. In Hostinger **File Manager** inside `public_html`, click **Upload** > choose `maintenance.zip`.
3. Right-click `maintenance.zip` and choose **Extract** directly into `public_html`.
4. Delete the `.zip` file.
